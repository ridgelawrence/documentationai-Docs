## Getting Started

To create a new project in WRLD:

1. Sign in at `https://app.wrld.com`
2. Click **New Project** on your dashboard
3. Name your project and set visibility
4. Click **Create**
5. Access your new project's workspace

You can now start adding docs from the sidebar. All changes auto-save.

## Tip

<Callout kind="tip">
You can invite teammates from the project settings anytime.
</Callout>
