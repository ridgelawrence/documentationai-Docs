## Cloud and hosting

Deploy reliably on WRLD's private cloud network. You manage solid-state drive (SSD) storage with full root access and a global content delivery network (CDN).

```javascript
// Example Node.js app deployment config
const config = {
  host: 'https://api.example.com',
  region: 'us-east',
  storage: 'ssd-100gb'
};
```

## Advanced integrations

<Expandable title="Web development API example" default-open="false">

Integrate WRLD services via API. Here's a multi-language example.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.example.com/v1/deploy', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer YOUR_TOKEN' },
    body: JSON.stringify({ site: 'myapp', framework: 'nextjs' })
  });
  const data = await response.json();
  console.log(data.status);
  ```
  ```python
  import requests
  response = requests.post(
      'https://api.example.com/v1/deploy',
      headers={'Authorization': 'Bearer YOUR_TOKEN'},
      json={'site': 'myapp', 'framework': 'nextjs'}
  )
  print(response.json()['status'])
  ```
</CodeGroup>
