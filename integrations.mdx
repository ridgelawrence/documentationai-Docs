## Overview

WRLD provides flexible integrations to connect your IT, cloud, and AI services with existing tools. Use the REST API for programmatic access, webhooks for real-time events, or pre-built connectors for popular third-party services.

<Columns cols={3}>

  </Card>
  <Card title="Webhooks" icon="zap" href="#webhooks">
    Receive instant notifications for events like ticket creation or service alerts.
  </Card>
  <Card title="Third-party" icon="plug" href="#third-party">

  </Card>
</Columns>

## API access

Access WRLD endpoints using HTTPS requests. All calls require Bearer authentication with your API key.

<ParamField header="Authorization" param-type="string" required="true">
  Bearer token: `YOUR_API_KEY`
</ParamField>

<ParamField query="account_id" param-type="string" required="true">
  Your WRLD account identifier.
</ParamField>

### List integrations

Retrieve a list of available integrations for your account.

<Request tabs="JavaScript,cURL" show-lines="true">
  ```javascript
  const response = await fetch('https://api.example.com/v1/integrations?account_id=YOUR_ACCOUNT_ID', {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  });
  const data = await response.json();
  ```
  ```bash
  curl -X GET "https://api.example.com/v1/integrations?account_id=YOUR_ACCOUNT_ID" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json"
  ```
</Request>

<Response tabs="200">
  ```json
  {
    "integrations": [
      {
        "id": "int_123",
        "name": "Slack Notifications",
        "status": "active",
        "events": ["ticket.created", "alert.triggered"]
      }
    ],
    "page": 1,
    "total": 5
  }
  ```
</Response>

## Webhook setup

Configure webhooks to push events to your endpoint.

<Steps>
  <Step title="Create webhook" icon="plus">
    In the WRLD console, navigate to Integrations > Webhooks > New Webhook.
    
    Enter your endpoint URL, e.g., `https://your-webhook-url.com/wrld`.
  </Step>
  <Step title="Select events" icon="zap">
    Select events like `ticket.created` or `service.alert`.
  </Step>
  <Step title="Verify & test" icon="check-circle">
    WRLD sends a test payload. Respond with HTTP 200 to confirm.
  </Step>
</Steps>

Example incoming payload:

````javascript
{
  "event": "ticket.created",
  "data": {
    "id": "ticket_456",
    "subject": "Server downtime",
    "priority": "high"
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
````

## Third-party integrations

WRLD supports connections to popular tools.

<Tabs>
  <Tab title="Slack" icon="message-circle">
    Send alerts and ticket updates to Slack channels.
    
    <CodeGroup tabs="JavaScript,Python">
      ```javascript
      await wrld.integrations.slack.connect({
        channel: '#alerts',
        events: ['alert.triggered']
      });
      ```
      ```python
      wrld.integrations.slack.connect(
        channel="#alerts",
        events=["alert.triggered"]
      )
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Zapier" icon="zap">
    Build no-code workflows with 5000+ apps.
    
    Use the WRLD Zapier app: search "WRLD" in Zapier and authenticate.
  </Tab>
  <Tab title="GitHub" icon="github">
    Sync issues with WRLD tickets for devops teams.
    
    <Callout kind="tip">
      Requires GitHub App installation from WRLD console.
    </Callout>
  </Tab>
</Tabs>
