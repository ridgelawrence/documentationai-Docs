## Prerequisites

<Callout kind="info">

Before starting, ensure you have:
- A valid business email address
- Access to your company's domain registrar (for custom domain setup)
- Basic information about your IT needs (e.g., current stack, user count)

</Callout>

## Create Your WRLD Account

Follow these steps to sign up for WRLD services.

<Steps>
  <Step title="Visit the Signup Page" icon="user-plus">
    Navigate to [https://wrld.host/signup](https://wrld.host/signup) in your browser.
  </Step>
  <Step title="Enter Your Details" icon="edit-3">
    Provide your business name, email, and phone number. Agree to the terms of service.
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your inbox for a verification email from WRLD and click the link to activate your account.
  </Step>
  <Step title="Complete Onboarding" icon="check-circle">
    Fill out the quick onboarding form with your team size and primary services needed (e.g., Managed IT or Cloud Hosting).
  </Step>
</Steps>

## Log In to the WRLD Console

Access your dashboard at [https://wrld.host/login](https://wrld.host/login).

<Tabs>
  <Tab title="Web Browser" icon="globe">
    Enter your email and password. Enable two-factor authentication for security.
  </Tab>
  <Tab title="CLI (Advanced)" icon="terminal">
    Install the WRLD CLI and authenticate:

    <CodeGroup tabs="npm,yarn">
      ```bash
      npm install -g @wrld/cli
      ```
      ```bash
      yarn global add @wrld/cli
      ```
    </CodeGroup>

    ```bash
    wrld auth login
    # Enter your API token from console settings
    ```
  </Tab>
</Tabs>

<Callout kind="tip">
  Save your login details securely. Use a password manager for multi-factor authentication codes.
</Callout>

## Submit Your First Service Request

Request Managed IT support as your first action.

<Steps>
  <Step title="Navigate to Requests" icon="plus-circle">
    Click "New Request" in the sidebar.
  </Step>
  <Step title="Select Service" icon="settings">
    Choose "Managed IT" and describe your needs (e.g., "Proactive monitoring for 50 users").
  </Step>
  <Step title="Submit & Track" icon="eye">
    Review details and submit. Use the ticket ID to track progress in real-time.
  </Step>
</Steps>

For API-based requests, use this example:

<Request tabs="cURL,JavaScript" show-lines="true">
  ```bash
  curl -X POST https://api.wrld.host/v1/requests \
    -H "Authorization: Bearer YOUR_API_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "service": "managed-it",
      "description": "Setup monitoring for 50 users",
      "priority": "medium"
    }'
  ```
  ```javascript
  const response = await fetch('https://api.wrld.host/v1/requests', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_TOKEN',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      service: 'managed-it',
      description: 'Setup monitoring for 50 users',
      priority: 'medium',
    }),
  });
  const data = await response.json();
  ```
</Request>
